# 2D Platformer Game

![Gameplay](gameplay.gif)

2D Platformer prototype built with Unity & C#.

> ⚠️ Project Status: Discontinued / Unfinished Prototype

## 🎮 About the Game

A 2D action game that combines level-based platforming with challenging Boss battles. The game features a variety of stages, each offering different challenges.

One of its key features is the **Quest Board system**, where players can freely choose from different quest notices. Each quest provides information about the stage, the Boss, and the rewards that can be earned.

Accept a quest, overcome the challenges, defeat the Boss, and claim your well-deserved rewards.

## ✨ Features

- 🏃 **Player Movement** – Run, jump, double jump, and collect items throughout the level.
- ⚔️ **Melee Combat** – Fight enemies using close-range weapons.
- 🗡️ **Attack Combo System** – Perform chained normal attacks using a basic combo system.
- 💨 **Ranged Sword Skill** – Use a special skill that launches a ranged sword slash.
- 👾 **Enemy System** – Includes one enemy type with basic combat behavior.
- 🗺️ **Playable Level** – Currently features one playable level.
- ❤️ **Health System** – The player has a health system for taking damage and surviving combat.
- 🔵 **Mana System** – Mana is used to support special combat abilities.
- 🎒 **Inventory System** – Collect and manage items through an inventory system.
- 🔊 **Audio System** – Includes sound effects and game audio.
- 🎞️ **Character Animations** – Player actions such as movement and combat are supported with animations.
